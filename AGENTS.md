# AGENTS.md: alexandr-khvostov

Public portfolio of Alexandr Khvostov: architecture case studies of projects they built or led, an interactive system map, and one pet project. Astro + Tailwind CSS v4, static, on GitHub Pages. Interviewers read it, so every claim must survive "show me how".

## Read before changing

- [docs/architecture.md](docs/architecture.md): before adding or moving files, components, pages, content fields or map logic. Folders, layers, content model, how the map is built.
- [docs/conventions.md](docs/conventions.md): before writing code, copy or styles, and before committing. Content sourcing, styling rules, imports, checks, git.
- [docs/workflow.md](docs/workflow.md): before planning a task or dispatching an agent. Roles and models, the code loop, the content loop, mentor mode.
- [DESIGN.md](DESIGN.md): before any styling, component, theme or animation work. Token layers, colors, type, motion, components.
- `research/_synthesis.md` (local only, git-ignored): before writing or editing case copy. Facts, agreed role wording, allowed names, what stays off the page.

## Always

- Chat with the developer in Ukrainian; everything in the repository is English.
- Install packages, download anything or spend money only after the developer's explicit yes.
- Commit only when the developer asks, with the developer as the only author.
